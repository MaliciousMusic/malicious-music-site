# Malicious Music — site

Site vitrine et de vente de Malicious Music :

- **Software** : plugin (VST probable) MP3 → stems mixés — formule unique à 59 €/mois.
- **Audioware** : gamme hardware (la Pyramide platine/range-vinyles/enceinte, les écouteurs géants-enceintes, le casque expérimental sans recharge avec stockage intégré).

Site statique (HTML/CSS/JS, aucune dépendance). Les contenus provisoires sont marqués avec la classe `.ph` (affichés en orange).

## Lancer en local

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000
